# Espectro Eletromagnético — Ciência em foco

Site educativo responsivo feito com HTML, CSS e JavaScript puro.

## Como visualizar
Abra `index.html` no navegador. Não precisa instalar dependências.

## Estrutura
- `index.html`: conteúdo e estrutura semântica.
- `style.css`: aparência responsiva e acessível.
- `script.js`: menu móvel e quiz interativo.

## Publicação
Este projeto é estático. Na Vercel, importe o repositório GitHub e use:
- Framework Preset: Other
- Build Command: deixar vazio
- Output Directory: `.` (ou deixar o padrão para site estático)
- Root Directory: `./`

Veja o arquivo `GUIA_DE_HOSPEDAGEM.pdf` que acompanha o pacote para o passo a passo.

## Observação científica
O conteúdo é introdutório. A classificação da região ultravioleta pode variar conforme o critério físico adotado; por isso, o site explica que UV de maior energia pode provocar danos fotoquímicos e que a fronteira com ionização não é tratada de modo idêntico em todas as convenções.
